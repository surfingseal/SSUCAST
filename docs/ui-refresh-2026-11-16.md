# SSU:CAST UI 개선 — 2026-11-16

기존 날씨 메타포를 유지하면서 정보 위계를 조정하고, 이전 화면 검토에서 확인한 문제를 수정했다. 현재 로컬 http://localhost:8080 에 새 빌드를 반영했다.

## 디자인 결정

- 바탕 #f4f7fb, 제목/브랜드 #142d4e, 본문 #1a2c43, 보조 문구 #50627a, 인터랙션 #245dca, 카드 흰색으로 정리했다.
- 로고를 워드마크와 작은 서비스 설명의 두 줄로 나누고, 모바일에서는 공지 건수만 간결하게 표시한다.
- 입체 날씨 장식과 큰 배경 SVG를 제거하고, 예보와 같은 평면 아이콘을 사용한다. 지속 반복 애니메이션을 제거했다.
- 어두운 남색 계열의 예보 보드와 밝은 검색·목록 영역을 구분한다. 밝은 날씨 단계도 흰 글자가 읽히도록 배경을 어둡게 조정했다.
- 모바일에서는 아이콘을 제목 옆에 배치해 세로 공간을 줄이고, 가로 예보에는 스크롤 안내를 제공한다.
- 주요 분류·남은 시간·검토 배지를 12px로 높였다. 모바일 검색 입력은 16px를 유지한다.

## 기능 수정

- 헤더가 콘텐츠에 맞춰 줄어들도록 조정하여 320px/375px에서 생기던 전체 페이지 가로 넘침을 해결했다. overflow-x:hidden으로 가리지 않았다.
- 필터 초기화를 검색 제목 옆으로 옮겨 모든 폭에서 사용할 수 있다. 검색 결과가 없을 때도 해당 위치에서 바로 초기화할 수 있다.
- `selectNoticeSchedule`이 마감 배지와 같은 미래 확정 일정을 고른다. 배지·일정명·날짜·상태가 같은 기한을 설명한다.
- 예: AI Challenge는 이미 지난 11/02 신청 기간 대신 배지의 기준인 '본선 제출: 발표 자료·영상 / 2026-11-25 13:00'을 카드에 표시한다. 상세보기의 전체 일정은 유지한다.
- 제출 일정의 '신청 중/마감/예정' 표시는 '제출 가능/마감/예정'으로 구분한다. 저장 데이터의 날짜나 상태는 변경하지 않는다.
- 로딩 중에는 '맑음'을 사실처럼 먼저 표시하지 않고 '확인 중'을 표시하며 aria-busy로 알린다.
- 모바일에서도 산정 기준을 열 수 있고, 좁은 화면의 예보 설정/정책은 인라인으로 펼쳐 넘침을 방지한다.
- 공고 목록 건너뛰기 링크와 명확한 키보드 포커스를 제공한다. 정책 링크의 부드러운 스크롤은 reduced-motion 설정을 존중한다.
