# 홈·공고 탐색 시안 구현

확정된 두 시안을 현재 Go 임베디드 HTML/CSS/JavaScript 웹에 적용했다. 새 UI 라이브러리는 추가하지 않았다. 기존 미커밋 서버/인증 변경은 유지했으며, 이 작업에서 크롤러·자동 실행·운영 MongoDB 쓰기는 실행하지 않았다.

## 디자인 기준과 대응

Figma `mGY5X3UrF13zDq9uAPvPuf`, `1:209 Dark Mood`의 고해상도 디자인 컨텍스트와 원본 자산을 읽었다. 첨부 시안은 홈 1568×1003, 공고 탐색 1478×1064 캡처를 기준으로 레이아웃 비율을 추정했다. 이미지 생성 시안의 텍스트/이미지 픽셀을 통째로 웹 배경으로 사용하지 않았다.

| 요소 | 원본/시안 기준 | 구현 |
| --- | --- | --- |
| 화면·패널·내부 카드 | #0f0f0f / #1e1e1e / #272727 | CSS 변수로 적용 |
| 칩·모서리 | #363636, 패널 24px | 원본 토큰 및 마크업으로 적용 |
| 사이드바 | 아이콘 전용, 선택 표시 | 홈·공고 탐색·예보·산정 기준으로 연결 |
| 상단 요약 | 가로 전체 패널, 요일/날짜, 우측 이미지 | 동적 한국 날짜, 공고 집계 연결 |
| 홈 하단 | 오늘 마감 / 7일 예보 | 기존 검증 마감 계산에 연결 |
| 공고 카드 | 두 열, 높이 유지, 하단 구분선/마감/상세 | 데스크톱 높이 156px, 하단 여백 실제 측정 13px |
| 카드 제목/설명 | 카테고리와 간격 확보 | 제목 위 12px 여백, 긴 실제 데이터는 말줄임 |
| 게시일·체크박스·탐색 제목 | 제거 | 목록에서 제거, 상세의 원문 메타는 유지 |
| 검색 | 공고명 검색 | 입력창 내부 placeholder와 제목 전용 API 검색 |

원본 Figma에서 제공된 27개 PNG/SVG를 `internal/web/static/figma`에 저장했다. `manifest.json`은 원본 코드 변수와 파일명의 대응을 기록한다. 주요 사용 슬롯은 다음과 같다.

- `8e098.png` 폭풍, `1022f.png` 비, `b0372.png` 맑음, `001c7.png` 구름: 상단 요약 및 날짜 카드. Figma의 이미지 fill 확대 비율을 예보 카드에 적용했다.
- `cfc22.png`: 원본 프로필. `d5a58.svg`, `1a992.svg`: 테마 전환.
- `a1e7c.svg`, `7b602.svg`, `982c3.svg`, `25cce.svg`: 사이드바/달력/도움말.
- `485a1.svg`, `9b069.svg`, `c9c63.svg`: 검색/학교/드롭다운.
- 원본의 우상단 지표 패널 등 확정 시안에서 제외된 요소의 자산도 보관했지만 화면에 임의로 추가하지 않았다.

생성 시안과 Figma 원본은 날씨 아이콘·인물의 세부 형태가 다르다. 사용자의 원본 자산 사용 지시에 따라 실제 화면에서는 Figma 원본을 사용했다. 공고 제목과 요약은 샘플 문구가 아닌 저장된 데이터여서 줄바꿈/말줄임이 달라질 수 있다. 실제 카테고리 전체를 유지했으며 모바일은 수평 스크롤로 탐색한다.

## 동작

- `/#home`, `/#explore`, `/#forecast` 해시로 화면을 전환한다. 기존 `/` 및 API 엔드포인트는 유지한다.
- 홈 검색은 검색어를 공고 탐색 탭으로 전달한다. 검색 상태·카테고리·출처·정렬·페이지는 URL에 유지한다.
- 기본 목록은 6개/페이지. 기존 `limit` URL 값도 지원한다.
- 검색 요청에 `search_in=title`을 추가했다. 이 값이 없는 기존 API 요청은 제목/요약/본문 검색을 유지한다. 검색어는 기존과 같이 정규식 리터럴로 이스케이프한다.
- 한국 시간 05:00~10:59 아침, 11:00~16:59 점심, 그 외 저녁. 분 단위와 탭 복귀 시 인사말/날짜/마감 표시를 갱신한다.
- 오늘 목록은 KST 오늘 마감하는 확인된 모집 공고만 사용한다. 시각이 이미 지났으면 제외하고 시각 미기재는 당일까지 포함한다.
- 관심 분야 선택, 날짜 선택 목록, 상세 모달, 원문 링크, 필터 초기화, 페이지 이동과 테마 전환을 연결했다.
- 프로필 이름/사진은 요청한 시안을 위한 고정 표현이다. 계정 조회·사용자 변경 API는 연결되어 있지 않다.

## 변경 파일

- `internal/web/static/index.html`, `app.css`, `app.js`: 홈/탐색 화면과 상호작용.
- `dashboard.js`, `dashboard_test.cjs`: 한국 시간 인사/날짜, 오늘 공고 선택, 자산 대응과 테스트.
- `figma/*`: 원본 이미지/SVG 및 매핑.
- `internal/web/web.go`, `web_test.go`: 로컬 자산 경로 허용 및 API/자산 회귀 검증.
- `internal/notices/notices.go`, `notices_test.go`: 선택적인 제목 전용 검색 조건 검증.
- `internal/repository/notices.go`, `notices_search_test.go`, `notices_integration_test.go`: 검색 범위 분기와 MongoDB 검증.

## 검증 결과

- JS 구문 검사 통과.
- 기존 마감 계산 테스트 15개 통과.
- 인사말의 6개 경계 시간, 한국 날짜/요일, 오늘 공고 선택, Figma 자산 대응 테스트 통과.
- 27개 원본 자산 파일 존재/비어 있지 않음 확인. 브라우저에서 표시 중인 모든 이미지 로드 성공, warning/error 로그 없음.
- `go test -race -count=1 ./internal/web ./cmd/web ./internal/notices ./internal/repository` 통과. `TEST_MONGODB_URI=mongodb://127.0.0.1:27030`인 별도 로컬 MongoDB에서 실행했고 임시 DB는 각 테스트가 소유권 검증 후 정리했다. 검증용 mongod는 작업 후 종료했다.
- 처음 샌드박스 안에서 실행한 Mongo 테스트는 loopback 연결 권한으로 실패했고, 동일 테스트를 권한이 허용된 로컬 환경에서 재실행해 통과했다.
- 관련 4개 패키지 `go vet` 통과. 웹 실행 파일 빌드 및 `go build ./cmd/... ./internal/...` 통과.
- `go build ./...`는 기존 `outputs/*/source-before`의 불완전한 백업 Go 코드에서 undefined type 오류로 실패했다. 이번 작업 범위와 무관한 보관 자료라 수정하지 않았다. 전체 저장소 테스트가 통과했다고 간주하지 않는다.
- 브라우저에서 제목 검색, 홈 검색 전달, 오늘/날짜별 마감 목록, 관심 분야, 상세보기, 카테고리, 필터 초기화, 페이지 이동, 0건 결과, 테마/산정 기준 확인.
- 홈과 탐색 320/375/768px 및 데스크톱 1568/1478px에서 문서 가로 넘침 없음. 데스크톱 6개 카드 모두 156px 높이 확인. 실제 모바일 기기 및 스크린리더 검증은 실행하지 않았다.

최종 로컬 실행: `http://localhost:8080/#home`, `http://localhost:8080/#explore`.
캡처: `outputs/design-implementation/home.jpg`, `explore.jpg`, `mobile-explore.jpg`.

## 결과 영역 내부 스크롤

공고 탐색에서는 화면 높이를 제한하고 `#explore-results`만 세로 스크롤되도록 분리했다. 검색·출처·카테고리는 위에 고정되며 구분선 아래 공고 수/정렬/목록/페이지 이동이 함께 스크롤된다. 결과 영역에 키보드 포커스를 줄 수 있다. 페이지나 필터가 바뀌면 결과 영역만 처음으로 돌아간다. 홈에는 이 높이·overflow 규칙을 적용하지 않는다.

검증: 1478×800에서 결과 스크롤 218.5px 후 검색창 y148 및 카테고리 y273.2 유지, window.scrollY=0. 375×800에서도 내부 결과 스크롤 및 가로 넘침 없음 확인. 다음 페이지 선택 후 결과 scrollTop=0 확인. 홈 복귀 시 body overflow=visible, 요약 패널 높이 368.5px 유지. 웹 관련 기존 테스트와 실행 파일 빌드 통과. 200% 브라우저 확대/RTL 검증은 이번 수정에서 실행하지 않았다. 캡처: `outputs/design-implementation/explore-scroll.jpg`.
