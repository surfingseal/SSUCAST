## 범위와 근거

현재 렌더링되는 홈의 마감 날씨·공지 목록, 공고 상세 모달, 검색 결과 없음 상태를 확인했다. 현재 화면 자체를 검토했으며 브랜치나 미커밋 변경의 도입/회귀 여부는 판정하지 않았다. 제품 코드는 수정하지 않았다.

스택은 Go embed + HTML/CSS/일반 JavaScript이며 외부 UI 프레임워크를 추가할 이유는 없었다. 프로젝트의 `docs/web-architecture.md`, `docs/deadline-weather.md`를 읽었다. 별도의 PRODUCT.md, DESIGN.md, CONTRIBUTING.md, CODING_STANDARDS.md, CLAUDE.md, AGENTS.md는 파일 검색에서 발견하지 못했다. 현재 존재하는 디자인 문서의 날씨 메타포와 원문 근거 우선 원칙을 기준으로 검토했다.

better-interface 및 여섯 better-* 도메인 스킬과 playwright-cli 사용 지침을 읽었다. playwright-cli 실행 파일은 환경에서 발견하지 못해 내장 브라우저의 접근성 트리·스크린샷·DOM 조회 기능으로 확인했다. 필요한 디자인 스킬은 이미 프로젝트에 설치되어 추가 다운로드하지 않았다.

## 확인한 장점

- 날씨 메타포에 '마감 N건', 남은 시간, 날짜를 함께 제공하여 아이콘과 색상에만 의미를 맡기지 않는다.
- 상세 모달은 AI 요약과 원문 근거를 구분하고 학교 원문 링크를 제공한다.
- 검색 입력은 접근성 이름이 있고 모바일 computed font-size가 16px였다.
- 공고 상세를 열었을 때 닫기 버튼으로 포커스가 이동했고 Escape로 닫힌 뒤 원래 제목 버튼으로 복귀했다.
- 검색 버튼에 Tab으로 진입했을 때 2.5px 포커스 outline이 나타났다. 대비 적합성까지 확인했다는 뜻은 아니다.
- 검색 결과가 없을 때 다른 검색어/필터 조정 안내가 표시되었다.

## 검증 기록

- 데스크톱에서 65건 전체 건수, 현재 조건 결과 27건, 1/3 페이지와 마감순 정렬/예정 일정 활성화 확인.
- AI Challenge 상세를 열어 신청 기한 11/02, 예선 제출 11/12, 본선 제출 11/25, 발표 11/27 표시 확인.
- 320px: innerWidth=320, documentElement.scrollWidth=434. 375px: innerWidth=375, scrollWidth=434. 모바일에서 reset.getClientRects().length=0.
- 존재하지 않는 검색어를 입력·검색해 결과 0건, 안내 문구, 이전/다음 비활성화 확인.
- 원래 URL과 기본 뷰포트로 복원했다. 관심 분야 등 저장되는 개인 설정은 변경하지 않았다.
- 수집된 브라우저 error/warn 로그 조회 결과 빈 배열이었다. 이 관찰만으로 모든 오류가 없다고 보장하지 않는다.
- 텍스트 대비 표본: #475569/흰색 7.58:1, #b45309/#fef3c7 4.51:1, #065f46/#ecfdf5 7.29:1, #5b21b6/#f5f3ff 8.19:1. 일반 텍스트 AA 기준 4.5:1 이상.
- 200% 줌, RTL, 오류/오프라인 상태 강제 재현, 전체 키보드 순회, 실제 스크린리더, reduced-motion 실행 및 전체 색상 조합은 미검증이다.
- 테스트·빌드·배포·데이터 수정은 이번 검토 범위에 포함하지 않았다.
