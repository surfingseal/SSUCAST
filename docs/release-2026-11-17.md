# 2026-11-17 웹 릴리스

이번 릴리스는 기존 읽기 전용 `cmd/web`을 배포한다. 수집기·스케줄러·AI 호출·DB 저장 도구를 웹 프로세스에서 실행하지 않는다.

## 포함한 변경

- 홈의 화면 높이 대응, 일별 마감 아이콘 연결, 공고 카드 크기 및 한 줄/두 줄 제목 정렬.
- 공고 목록 스크롤바의 스크롤 중/호버 표시와 카테고리 호버 배경.
- 홈 우측 패널의 한 장짜리 ‘이번 주 한눈에’: 실제 공고 기준 7일 내 중복 제외 건수와 집중 마감일. 개별 공고명과 불필요한 이동 버튼 제거.
- 홈 검색의 공고명 후보, 최근 검색어 5개, 지우기, 키보드 선택 및 한글 조합 처리. 후보 조회 취소와 이전 응답 방어.
- 공고 탐색의 여러 카테고리 선택, 필터 URL 정리, 홈과 동일한 패널 배치. 홈에만 상단 바 표시, 테마 전환 제거.
- 월간 캘린더, 별도 MongoDB에 저장한 AI 예상 공고 조회와 표시 전환.
- ‘마감 캘린더 / 선배의 오늘’ 전환, 선배/활동 선택, 준비 기록 팝업. 선배 데이터는 번들된 시연용 자료로 실제 공고와 분리한다.
- 새로운 정적 파일만 허용 목록에 추가하고 테스트 소스·환경 설정·로컬 결과 파일은 공개하지 않는다.

## 배포 전 검증

- 로컬 MongoDB `127.0.0.1:27031`의 독립 테스트 DB로 `go test -race -count=1 ./internal/... ./cmd/...` 통과.
- `go vet ./internal/... ./cmd/...` 통과.
- dashboard/calendar/weather/seniors/home-search JavaScript 테스트 5종 통과.
- `docker build -f Dockerfile.web -t ssucast-web:release-20261117 .` 통과.
- 로컬 실제 브라우저에서 홈, 검색, 다중 분류, 캘린더/선배 전환 및 팝업, 390px 모바일/1512px 데스크톱 화면 확인.

전역 `go test ./...` 대신 소스 범위를 명시했다. 무시된 `outputs/` 안에 보관한 불완전한 과거 Go 코드 사본은 빌드 대상이 아니다. 운영 배포 후 해당 커밋과 Render 성공 상태, 공개 웹의 정적 자산 및 실제 화면을 확인한다.
