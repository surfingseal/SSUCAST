## 전체65건과 결과31건 불일치

예전 `upcoming=true` URL이 제거된 예정 일정 체크박스의 조건을 계속 적용했다. 실제 해당 URL에서 출처 메타65건/결과31건 및 앞으로의 일정만 표시 문구를 재현했다. 프런트엔드 상태·URL 읽기에서 삭제된 `upcoming`, `has_schedule` 조건을 제거하고 숨은 필터 안내도 제거했다. REST API의 기존 두 파라미터 지원과 서버 정렬은 그대로 유지했다.

같은 예전 URL을 새로고침한 뒤 URL이 `?page=1&sort=deadline#explore`로 정리되고 출처65건/결과65건으로 일치함을 확인했다. 정렬 자체는 공고 수를 줄이지 않는다. 검색·카테고리·출처를 선택한 경우에는 출처 탭의 전체 데이터 수와 조건에 맞는 결과 수가 달라질 수 있다.
