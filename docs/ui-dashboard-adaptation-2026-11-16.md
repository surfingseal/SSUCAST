# 공고 대시보드 구성 개선

Figma Weather Forecast Dashboard는 정보 배치 참고로만 사용했다. 원본의 다크 테마, 프로필, 아이콘 메뉴, 온도·습도 지표와 이미지 자산은 가져오지 않았다. 기존 SSU:CAST의 밝은 공고 목록과 남색 요약 패널을 유지했다.

## 화면과 동작

- 상단: 오늘의 학교 공고 안내 및 전체 목록 이동.
- 왼쪽: 마감 날씨, 설명, 관심 분야 선택, 산정 기준. 24시간 이내·3일 이내 마감 공고 수와 일정 확인 필요 공고 수를 기존 계산 결과에서 표시한다. 24시간과 3일은 중첩 집계다.
- 오른쪽: 확인된 앞으로의 모집 마감 중 가장 가까운 공고 3건. 선택하면 기존 상세 모달을 연다. 예정된 마감이 없으면 빈 상태를 표시한다.
- 아래: 독립된 밝은 7일 예보. 날짜 선택 시 해당일 모집 마감 목록을 연다.
- 모바일: 요약, 다가오는 마감, 예보 순으로 한 열에 배치한다.
- 검색, 출처·카테고리 필터, 정렬, 페이지네이션과 기존 API는 유지한다.

## 변경 파일

- `internal/web/static/index.html`: 대시보드 제목, 요약 지표, 마감 목록 및 예보 제목 구성. 페이지 제목은 h1, 마감 날씨는 h2.
- `internal/web/static/app.js`: 기존 `renderSpotlight`를 화면에 연결하고 계산 결과를 세 지표에 반영.
- `internal/web/static/app.css`: 두 열 개요와 독립 예보, 반응형 스타일. 사용하지 않던 이전 spotlight 스타일을 정리.

새 라이브러리, Figma 이미지 다운로드, 외부 학교 크롤링, DB 쓰기는 없다. 기존 서버 변경 사항은 유지했다.

## 검증

- `go test -race ./internal/web ./cmd/web ./internal/notices` 통과.
- 같은 패키지 `go vet`, `cmd/web` 빌드 통과.
- JS 구문 검사 및 기존 마감 계산 테스트 15개 통과. 호스트 Node 실행 환경 문제로 Node REPL에서 실행.
- 브라우저 320/375/768/1280px에서 문서 가로 넘침 없음.
- 다가오는 마감 상세보기, 날짜별 마감 목록, 검색 0건 후 필터 초기화 및 공고 12개 복원 확인.
- 브라우저 warning/error 로그 없음.
- 전체 저장소 테스트 및 실제 모바일 기기·스크린리더 검증은 이번 작업에서 실행하지 않았다.
